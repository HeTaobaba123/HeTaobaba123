# HeTaobaba123

Independent developer building multilingual reference sites and open datasets for Chinese metaphysics, Arabic-language content, and MENA markets.

## Sites

| Site | Language | What it is |
|---|---|---|
| [DaoPaths](https://daopaths.com) | English | BaZi (Four Pillars), Zi Wei Dou Shu, He Hun and I Ching tools with stated calculation limits |
| [TCMHub](https://aicatalogx.com) | Arabic / Chinese | Traditional Chinese Medicine reference library, including a cupping (hijama) guide |
| [ToolCraftX](https://toolcraftx.com) | Arabic | Arabic AI tool collection and prompt library |
| [PanguDawn Novels](https://ar.pangudawn.com) | Arabic | Arabic-translated Chinese web novels |
| [HanseBrief](https://hansebrief.com) | Chinese / English | China–Arab trade news reference |

## Open datasets

- [I Ching 64 hexagrams](https://github.com/HeTaobaba123/iching-64-hexagrams-dataset) — structured hexagram, line and judgment data
- [DaoPath terms](https://github.com/HeTaobaba123/daopath-terms-dataset) — four-language terminology (EN / ZH-Hans / ZH-Hant / AR)
- [TCM Arabic dataset](https://github.com/HeTaobaba123/tcm-arabic-dataset-) — Arabic–Chinese TCM terminology
- [Arabic–Chinese novels metadata](https://github.com/HeTaobaba123/arabic-chinese-novels-dataset) — novel and chapter metadata
- [HanseBrief trade news](https://github.com/HeTaobaba123/hansebrief-trade-news-dataset) — bilingual China–Arab trade news corpus
- [Arabic AI prompts](https://github.com/HeTaobaba123/toolcraftx-arabic-prompts) — production-oriented Arabic prompt templates

## Notes

- Datasets are published for research and reference. Check each repository's license before redistribution.
- Traditional systems on the sites above are presented as cultural and interpretive frameworks, not medical, legal, or financial advice.
